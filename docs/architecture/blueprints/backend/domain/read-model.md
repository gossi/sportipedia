# Read Model

The queryable projection of the events. Typed Ecto schema plus the changesets
the projections need.

## Prerequisite

- The [Domain Model](../../../../domain-model/README.md) contains the read
  model's `schema`, its `projections`, and the aggregate invariants that make a
  field unique.

## What the generator does

`use TypedEctoSchema`, `import Ecto.Changeset`, `@primary_key` (id, not
autogenerated), `@timestamps_opts` in microsecond precision, `@schema_prefix`
from the subdomain, the `typed_schema` fields from the model's `schema` with the
mapped Ecto types, `timestamps()`, and `insert_changeset/2` plus
`update_changeset/2` casting the fields they need — with a
`unique_constraint(:<field>)` for every unique-field invariant.

The `@moduledoc` describes what the read model represents, from the model's
projection rules.

## Left to you

- The table: `mix ecto.gen.migration`, including the unique index a
  `unique_constraint` needs ([migration](./migration.md)).
- A custom changeset, only when `insert_changeset`/`update_changeset` cannot
  express the projection.

## Tests

No test file of its own: the read model is tested where it is written — the
[projector](./projector.md) cases in the
[event test](./event-test.md) — and where it is read, in the
[operation test](./operation-test.md).
